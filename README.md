# business-neta-notes

会社と仕事の「へぇ」を集めた、SNS投稿用のネタ帳です。

## テーマ

- **時短テク**：Excel・PowerPointなどのショートカット、仕事の敬語・ビジネスマナー
- **会社のルーツ**：企業の歴史、商品の誕生秘話
- **ビジネスの教養**：決算の読み方、仕事術、ハーバード・ビジネス・スクールの有名ケース

## ファイルの構成

- `neta/2026-11-01-initial.md`：初版のネタ帳
- `neta/2026-11-01-office-terms.md`：知ってるようで説明できない仕事用語
- `neta/YYYY-MM-DD.md`：毎週月曜に追加される週ごとのネタ（最新ニュース5本＋定番ネタ10本）

日付が新しいファイルほど最新のネタです。
